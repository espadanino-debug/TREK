# trainwithnajib

Website for Najib's online fitness coaching (Fes, Morocco). It is a static site:
plain HTML, CSS and JavaScript, generated by one Python script. It lives in its
own folder and does not touch the TREK app.

## What is in it

- **Pages** in English (`/`) and French (`/fr/`): home, services, pricing,
  about, blog with five articles, contact. 22 pages in total.
- **3D** with Three.js: a dumbbell, a kettlebell and weight plates built in
  code, lit in green. They react to the pointer, to scrolling, and on the home
  page to the goal picker (heavier goals slide extra plates onto the bar).
- **Motion** with GSAP: scroll reveals, photo parallax, card tilt, a count-up.
- **Colours**: green, black and grey, with a dark and a light theme.

## Settings you can change without rebuilding

`config.js` holds the things most likely to change:

- `whatsapp`, `email`, `instagram`
- `calendly`: your booking link. While it is empty, "Book a call" opens WhatsApp.
- `payLinks`: one payment link per plan (Stripe Payment Link, PayPal, ...).
  While a link is empty, "Card or PayPal" opens WhatsApp so you can send the
  link yourself.
- `photo`: path to your photo, e.g. `assets/img/najib.jpg`. Shown on the About page.
- `transformations`: real client before/after photos. The section on the home
  page appears once this list is not empty.

## Changing text, prices or pages

All text lives in `tools/build.py`, written once with both languages side by
side: `{{English||French}}`. After editing it, regenerate the pages:

```bash
python3 tools/build.py        # pages, sitemap.xml, robots.txt
bash tools/build.sh           # same, and also rebuilds the 3D bundle (needs Node.js)
```

Do not edit the generated `index.html` files by hand; the next build overwrites
them. The 3D source is `tools/scene.src.js`.

If the site moves to its own domain, change `SITE` at the top of
`tools/build.py` and rebuild, so canonical links, the sitemap and the share
image point at the new address.

## Search (SEO)

- One language per URL, with `hreflang` links between the English and French
  versions, a canonical link, and a unique title and description on every page.
- Structured data: business, person (NASM credential), prices, FAQs,
  breadcrumbs and articles.
- `sitemap.xml` and `robots.txt` are generated.
- Page titles, headings and two of the articles are built around the search
  terms from the keyword research: online fitness coach, online personal
  trainer, fitness and nutrition coach, personalized fitness coaching, personal
  trainer for women, personal trainer for beginners, fitness coach for weight
  loss, at-home personal training, how much a personal trainer costs, and
  fitness coach vs personal trainer.

## Speed

- CSS is inlined, scripts are deferred, images are greyscale WebP in three
  sizes with width and height set.
- The 3D code (about 125 KB compressed) loads only after the visitor first
  moves, touches or scrolls. Until then a still frame of the same object is
  shown, so the first paint does not wait for it.
- Lighthouse, mobile, measured locally: 100 for performance, accessibility,
  best practices and SEO on the home, services, pricing and about pages.

## Preview locally

```bash
python3 -m http.server 8000     # run inside this folder, then open http://localhost:8000
```

## Deploy

Vercel project `trainwithnajib`, Root Directory `trainwithnajib`, no build
command. `vercel.json` sets long cache headers for `/assets/` and redirects the
old `.html` addresses.
